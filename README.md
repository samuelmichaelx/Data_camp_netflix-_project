# Netflix Data Analysis: Exploring the 1990s Decade 🎬

A data science project focused on performing Exploratory Data Analysis (EDA) on a dataset of Netflix titles. The primary goal of this analysis is to dive deep into cinema history and understand the characteristics of movies released during the **1990s decade** (1990–1999), specifically analyzing movie runtimes and genre trends.

## 📌 Project Overview
As part of an investigative data science workflow, this project explores a modified subset of Netflix data to answer specific historical questions about 90s cinema:
1. **What was the most frequent movie duration (the mode) during the 1990s?**
2. **How many short action movies (under 90 minutes) were produced in that decade?**

This project demonstrates foundational data manipulation skills using the `pandas` library, including multi-conditional filtering, statistical aggregation, and subset slicing.

## 📊 Key Findings
* **Most Frequent 90s Movie Duration:** `94` minutes.
* **Short 90s Action Movies (< 90 mins):** `7` movies identified in the dataset.
